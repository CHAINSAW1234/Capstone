# Capstone - VR 교육 시스템: 실시간 피드백 및 AI Agent 기반 절차형 학습 모듈

부산대학교 정보컴퓨터공학부 2024 후기 캡스톤 프로젝트  
**실시간 피드백 및 AI Agent 상호작용 기반 VR 절차형 학습 시스템 구축**


## 📌 프로젝트 개요

VR 기반 훈련 시스템은 몰입도를 높여 실습 중심의 교육 효과를 제공하나, 기존 시스템은 **실시간 절차 피드백 부족, 순서 오류 감지 부재, 실시간 질의응답 부재**라는 한계가 존재했습니다.

본 프로젝트는 이를 해결하기 위해:
- 사용자의 절차 기반 행동을 **실시간으로 모니터링, 오류 감지 및 피드백 제공**
- **AI Agent** 기반 음성 상호작용 및 질의응답 제공
- 화재 대피 및 소화기 사용 시나리오를 기반으로 절차형 학습을 가능하게 합니다.

## 🗂️ 주요 기능

### 1️⃣ 실시간 절차 피드백

- **절차 기반 시퀀스 락:** 단계 미완료 시 다음 단계 불가
- **오류 발생 시 즉각 피드백:** UI/음성/진동으로 경고
- **End UI 절차별 평가:** 누락/오류 단계 시각 표시 및 상세 설명 제공

### 2️⃣ AI Agent 기반 상호작용

- 음성(STT) → Gemini API 처리 → TTS 음성 안내
- 사용자가 질문 (“문이 어디야?”, “다음 단계는?”) 시:
  - 관련 오브젝트 하이라이트 및 방향 안내
  - 음성 및 시각 가이드 제공
- 평균 질의응답 응답 속도: **4.06초 (Send + Response Time)**

### 3️⃣ 절차형 시나리오 기반 학습

#### 🧯 화재 대피 훈련
- 화재 인지 (연기/경보)
- 젖은 천 호흡 보호
- 문 온도 확인
- 비상 경보
- 연기 속 포복 (머리 0.5m 이하 유지)
- 비상문 탈출
- 맵 랜덤화로 반복학습 방지

#### 🔥 소화기 사용 훈련
- 소화기 들기
- 안전핀 제거
- 노즐 조준 (각도 30도 이내)
- 분사 및 화재 진압

### 4️⃣ 연습모드 & 평가모드

## 사용된 기술 스택

### 개발 언어
- **C#**: Unity 기반 개발.
- **C++**: 성능 최적화 및 데이터 처리.

### 개발 도구
- **Unity**: 3D 환경 개발 (Unity Editor: 6000.0.32f1).
- **Blender**: 애셋 제작 (화재 환경, 헝겊, 방화벽 등 모델링).
- **Adobe Premiere Pro & Photoshop**: UI 및 시각 자료 제작.

### 사용 장비
- **Oculus Quest 2**: VR 테스트 및 시뮬레이션.


## 설치 및 실행 방법

### Prerequisites
- Unity 6000.0.32f1 이상 설치
- Oculus Quest 2 (또는 호환 가능한 VR 기기)
- XR Interaction Toolkit 설치

### 설치방법
1. 이 저장소를 클론합니다:
   ```bash
   git clone https://github.com/[Your-GitHub-Username]/[Your-Repo-Name].git
   ```
2. Unity Hub에서 프로젝트를 열고, Assets/Scenes/MainScene을 실행합니다.
3. VR 기기를 연결하고, Oculus Link를 통해 디바이스와 연동합니다.
4. Unity에서 Play 버튼을 눌러 실행합니다.
